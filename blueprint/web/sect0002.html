On the Lorentzian hyperboloid model \(\mathbf{H}^n = \mathrm{Hyperboloid}(E)\) equipped with its Levi-Civita connection, \(B_\xi \) is \(C^\infty \) and its Riemannian Hessian satisfies the exact identity

\[ (\operatorname {Hess}B_\xi )_y(X, Y) = g_y(X, Y) - dB_\xi (y)(X)\, dB_\xi (y)(Y). \]

In particular, \((dB_\xi (y)(X))^2 \le g_y(X, X)\) and \((\operatorname {Hess}B_\xi )_y(X, X) \ge 0\).

For weights \(w : \iota \to \mathbb {R}\) and boundary directions \(\xi : \iota \to S(E)\), the Busemann barycenter functional on \(\mathrm{Hyperboloid}(E)\) is \(\mathcal{B}_w(y) = \sum _{i \in \iota } w_i e^{B_{\xi _i}(y)} = -\langle y, Z(w)\rangle _{\mathcal{L}}\), where \(Z(w) = (\sum _i w_i, \sum _i w_i \xi _i) \in \mathbb {R}\times E\) is the resultant Lorentz vector. When \(\| \sum _i w_i \xi _i\| {\lt} \sum _i w_i\), the future-timelike normalization \(\mathrm{hyperboloidBarycenter}(w, \xi ) = Z(w)/\| Z(w)\| _{\mathcal{L}} \in \mathrm{Hyperboloid}(E)\) defines the explicit barycenter, with normalized probability weights \(p_i(w) = w_i e^{B_{\xi _i}(p)} / \mathcal{B}_w(p)\).

If \(z_i \ge 0\) on \(\mathrm{Fin}\, n\) satisfy \(\sum _{i=1}^n z_i \le 1\) and \(\prod _{i=1}^n z_i = (1/n)^n\), then \(z_i = 1/n\) for all \(i\). Consequently, if \(|\det D^{\mathrm{Riem}} F_s(p)| = (s/n)^n\) with \(s {\gt} 0\), then:

  1. Both source and target Busemann covariance tensors are isotropic: \(H_1 = H_2 = \frac{1}{n} \operatorname {id}_E\).

  2. \((D^{\mathrm{Riem}} F_s(p))^* D^{\mathrm{Riem}} F_s(p) = (s/n)^2 \operatorname {id}_E\), so \(D^{\mathrm{Riem}} F_s(p)\) is a scaled linear isometry with scale factor \(s/n\) (and an exact Riemannian linear isometry when \(s = n\)).

Proof ▶

Strict concavity of \(\log t \le t - 1\) forces all eigenvalues of \(H_1, H_2\) and \(A^* A\) to be equal, and \(L^1\) saturation of \(\int _X (f - g)\, d\mu _X = 0\) with \(f \le g\) upgrades global volume equality to \(\mu _X\)-a.e. pointwise equality.
